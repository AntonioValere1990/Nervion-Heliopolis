Podcast independiente del Sevilla y el Betis. Dos colores. Una ciudad. Todo el fútbol.

**App pública (se instala en el móvil):**  
https://podcast-nervionyheliopolis.github.io/NervionyHeliopolis/

- Android (Chrome): menú ⋮ → Instalar aplicación
- iPhone (Safari): Compartir → Añadir a pantalla de inicio

No afiliado oficialmente a Sevilla FC ni Real Betis Balompié.
